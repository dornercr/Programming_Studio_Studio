This file intentionally executes undefined behavior to demonstrate a diagnostic.
It is excluded from the normal CMake targets. Do not use it as application code.
From this chapter directory, on a supported Clang/GCC development environment:
  c++ -std=c++20 -g -O1 -fsanitize=address -fno-omit-frame-pointer optional/unsafe_demo.cpp -o unsafe_demo
  ./unsafe_demo
Expected outcome: a nonzero diagnostic run, not PASS. Exact output depends on the tool.
The shipped verification report states whether this negative exercise was run.
