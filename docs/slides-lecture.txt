STUDY STUDIO — BOOK I, CHAPTER 1: INTERACTIVE SLIDES

WHAT THIS PATCH ADDS
A Slides tab for Book I · C++ Foundations with 26 Chapter 1 slides.
Slide and example appear together, with editable C++, online compilation,
program input/output, C++17/C++20 experiments, build-stage walkthroughs,
revealable questions, verbatim narration and presenter directions.
Includes presentation view, a resizable divider, keyboard controls, mobile
layout, saved slide/code drafts and source downloads.

APPLY THE PATCH
This source patch targets the supplied Design_Patterns_Study_Studio ZIP.
Open a terminal in your project's root: the folder containing package.json,
src/ and scripts/. If you use Git, save or commit your current work first.
Download Book_I_Chapter_1_Slides.patch into that root, then run:

    git apply --check Book_I_Chapter_1_Slides.patch
    git apply Book_I_Chapter_1_Slides.patch
    npm ci
    npm run build
    npm test
    npm start

The check must succeed before applying. If it reports conflicts, the source
has changed since the supplied ZIP; have the patch rebased to your current
source. Node 20.11 or later is required by the project; Node 22 is suitable.
Git's apply command also works inside an extracted source folder.

OPEN THE LECTURE
Visit http://localhost:5173/?course=cpp-book-01&chapter=1&view=slides
Or select Book I · C++ Foundations → Chapter 1 → Slides.

TEACH FROM THE PAGE
1. Click Present for the focused lecture view. Press Escape to exit.
2. Use Next/Previous, the slide selector, or left/right arrow keys.
3. Open Presenter script and directions for each slide's SAY and DO text.
   These notes are visible on the same page: close them before sharing the
   audience display. This patch does not create a separate presenter window.
4. On code slides, edit the program, choose an experiment/language mode,
   predict the result, then click Run online (or Ctrl/Cmd + Enter).
5. Compare the actual result with Expected behavior of the original example.
   The expected panel describes the original code, even after you edit it.
6. Drag the divider or focus it and use arrow keys to resize the panes.
7. Press N to toggle the script, P to toggle presentation, Home/End to jump.
   Navigation shortcuts leave typing in text fields alone.
8. Download .cpp to keep an individual source file. Export lecture work saves
   a JSON copy of slide drafts/settings; there is no restore/import UI yet.

LOCAL DEMONSTRATIONS
The shell/pipeline and stale-executable examples are clearly labeled
walkthroughs. To execute their commands, download main.cpp from slide 14,
put it in a working folder, open a Bash/GCC terminal there and create the
build folder with mkdir -p build. Intermediate artifacts require your local
compiler and shell. The webpage does not execute shell commands.

ONLINE AND OFFLINE
Run online explicitly sends the current editor's source and input to the
same Compiler Explorer service used by the existing Coding Lab. It requires
internet and a working compiler service. Nothing is sent automatically.
Drafts and slide position are saved in this browser under a separate Slides
storage key. The existing study backup does not include these drafts; use
Export lecture work for a readable JSON copy.

To build the portable version:

    npm run build:offline

Open dist-offline/index.html. Slides, narration, questions and code editing
work without internet. Online compilation still needs internet.

DEPLOYMENT
The existing GitHub Pages workflow runs npm run build, which now invokes
scripts/build-slides.mjs. Commit the patched source files through your normal
workflow to publish them. No generated dist files are included in this patch.
The original modular and offline builders are preserved beneath the wrapper.

CONTENTS / AUTHORING
lectures/manifest.json registers the lecture.
lectures/cpp-book-01/ch1.json contains its slide content, SAY and DO text.
src/slides.js and src/slides.css provide the interactive display.
scripts/build-slides.mjs attaches this layer to both existing builds.
src/app.js adds navigation/routing hooks; package.json routes build scripts.
tests/slides.test.mjs and tests/slides.browser.mjs cover the new behavior.
The modular site fetches lecture JSON only when Slides opens.
